# CougarAI · DataJam 2026

Landing site for **DataJam 2026**, the CougarAI two-day data science and machine learning competition at the University of Houston (Nov 7–8, 2026).

## Contents

- `index.html` — standalone static landing page. Open it directly in a browser or serve the directory with any static file server.

## Preview locally

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```
